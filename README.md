# Ruta Joven San Gabriel — Orientación para la Empleabilidad y el Emprendimiento
[Proyecto](https://github.com/Vero16am/ProyectoSG)

## Propósito

Contribuir al fortalecimiento de las capacidades de empleabilidad y emprendimiento de los jóvenes entre 18 y 28 años del municipio de San Gabriel, mediante el diseño de un servicio piloto de orientación que permita identificar sus necesidades, desarrollar habilidades para acceder a oportunidades laborales y facilitar su acercamiento a la oferta institucional disponible, considerando las particularidades de los sectores urbanos consolidados, periféricos y rurales.

## Alcance

El proyecto comprende la planeación, organización y ejecución simulada de un servicio piloto de orientación juvenil, estructurado en cuatro módulos: diagnóstico individual, orientación para la empleabilidad, orientación para el emprendimiento y remisión a la oferta institucional. Su desarrollo contempla la preparación de materiales, convocatoria e inscripción de participantes ficticios, caracterización de necesidades, acompañamiento en habilidades laborales y emprendimiento, así como el seguimiento y cierre del piloto.
