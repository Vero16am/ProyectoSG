# ProyectoSG
Ruta Joven San Gabriel es un proyecto académico que simula un servicio piloto de orientación para jóvenes de 18 a 28 años en sectores urbanos y rurales. Incluye diagnóstico individual, empleabilidad, emprendimiento y acceso a la oferta institucional. GitHub permitirá gestionar actividades, responsables, avances, evidencias y seguimiento.
